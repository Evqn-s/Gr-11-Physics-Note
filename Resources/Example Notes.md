Average Velocity = Displacement/Time Taken $\vec{v}_{\text{avg}} = \frac{\Delta \vec{d}}{\Delta t}$

Position, Displacement and Distance(Vectors)

Position is the specific location of an object at a given moment relative to a reference point, while displacement is the net straight-line change from an object's initial position to its final position. So displacement is how much something moves while position is just the distance between.

A triangle means a change in position. Displacement = Change of Position. $\triangle$ Distance also means a change in position so it also uses the triangle.

To find the change of position ie displacement it’s $\triangle \vec{d} = \triangle \vec{d}_f - \triangle \vec{d}_i$ so the original position - the current position.

Position is to a reference point(usually the origin 0,0, so for example x=4) while displacement is the change from the original position to the final one displacement = 2 because x=4 and then moved to x=6. Sometimes you have to make up the reference position

To write the direction of a vector, write the magnitute and then the direction in square brackets. so 175km/h[N]

Distance is the the path an object travels, so if an object travels in a loop, displacement only measures the shortest path between the start location and the final location while distance measures the whole loop.
