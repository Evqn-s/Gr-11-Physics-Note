# Subject 2: Scalar & 1D Vector Motion Summary

> [!info] 1-Page Quick Reference
> High-yield summary of scalars, vectors, 1D position conventions, displacement, and speed vs. velocity for Gr. 11 Physics.

---

### Scalars vs. Vectors Comparison Table

Scalars are values that only have magnitude (amount and unit), while vectors have magnitude and a spatial direction.

| Type | Physical Quantities |
| :--- | :--- |
| **Scalars** | Mass ($m$), Time ($\Delta t$), Distance ($d$), Speed ($v$), Energy ($E$), Work ($W$) |
| **Vectors** | Position ($\vec{d}$), Displacement ($\Delta\vec{d}$), Velocity ($\vec{v}$), Acceleration ($\vec{a}$), Force ($\vec{F}$) |

---

### Core Kinematic Definitions
* **Position ($\vec{d}$):** Location of an object at a given moment relative to a chosen reference point (origin). Written with direction: e.g., $\vec{d} = +4.0\text{ m [E]}$.
  - *Deeper guide:* See [[Subject 2 - Vector Motion Foundations Guide#Position, Distance, and Displacement|Position, Distance, and Displacement]].
* **Displacement ($\Delta\vec{d}$):** Straight-line change in position from start to finish. Independent of path taken:
  $$\Delta\vec{d} = \vec{d}_f - \vec{d}_i$$
* **Distance ($d$):** Total length of the actual path traveled. Always positive ($d \ge 0$).
* **Average Speed ($v_{\text{avg}}$):** Total path distance divided by elapsed time (scalar):
  $$v_{\text{avg}} = \frac{d_{\text{total}}}{\Delta t}$$
* **Average Velocity ($\vec{v}_{\text{avg}}$):** Net displacement divided by elapsed time (vector):
  $$\vec{v}_{\text{avg}} = \frac{\Delta\vec{d}}{\Delta t} = \frac{\vec{d}_f - \vec{d}_i}{\Delta t}$$
* **Constant vs. Instantaneous:** Instantaneous speed is the speedometer reading at a single moment. Constant velocity means speed and direction never change, so $\vec{v}_{\text{inst}} = \vec{v}_{\text{avg}}$.

---

### Vector Notation Standards
* **Format:** Magnitude + Unit + `[Direction]` $\longrightarrow$ e.g., $\vec{v} = 175\text{ km/h [N]}$.
* **Direction Signs:** In 1D motion, define a positive axis:
  - Let $[\text{East}] = (+)$, $[\text{West}] = (-)$ or Let $[\text{Up}] = (+)$, $[\text{Down}] = (-)$.
  - Algebraic operations: $+15\text{ m/s}$ means forward; $-15\text{ m/s}$ means backward ($15\text{ m/s [W]}$).

---

### How-To: 1D Line Diagrams & Sign Setup
*See full methodology in [[Subject 2 - Vector Motion Foundations Guide#Constructing 1D Motion Line Diagrams|Line Diagram Construction Guide]].*

1. **State Direction Convention:** Explicitly write `Let [E] = (+)` before writing any math.
2. **Mark Origin ($0$):** Set a clear reference point on the line.
3. **Sketch Displacement Arrows Tip-to-Tail:**
   - Draw an arrow for each leg: positive legs point right, negative legs point left.
4. **Compute Vector Sum:**
   $$\Delta\vec{d}_{\text{total}} = \sum \Delta\vec{d}_i = (+d_1) + (-d_2) + \dots$$
5. **Convert Final Result:** Convert negative scalar sums back into explicit bracketed directions: $-8\text{ m} \to 8\text{ m [W]}$.
